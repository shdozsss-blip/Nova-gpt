~1.1 GB

~1.6 GB

High reasoning density trained on synthetic and textbook data, fits comfortably within 4GB phones.

How to get a GGUF model:
  1. Download any compatible `.gguf` file (e.g. from HuggingFace `TheBloke` or `Qwen` repositories).
  2. Transfer the file to your Android device Downloads or internal storage.
  3. Click Import GGUF Model above and select the `.gguf` file.

About NOVA OFFLINE

Architecture, privacy principles, and system specs.

🛡️

Autonomous Offline Guarantee

NOVA OFFLINE is engineered from the ground up to run entirely on the local device:

  • Zero Telemetry: No analytical trackers, third-party loggers, or cloud pings.
  • Airplane Mode Certified: Once a GGUF model is loaded, zero network is required.
  • Local SQLite Storage: All chat records and settings remain strictly in private app storage.
